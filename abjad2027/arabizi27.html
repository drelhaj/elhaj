About the shared task

Connecting Arabizi and Arabic script

AbjadTranslit 2027 focuses on sentence-level transliteration between Arabic written in Latin characters, commonly known as Arabizi, and Arabic script. The task uses parallel text to study conversion in both directions.

Latin → Arabic

Arabizi to Arabic script

Given a sentence written in Arabizi, produce the corresponding sentence in Arabic script.

Arabic → Latin

Arabic script to Arabizi

Given a sentence in Arabic script, produce the corresponding sentence in Arabizi.

↔

Parallel text, sentence by sentence

The shared task centres on paired Arabizi and Arabic-script sentences. Dataset access, release details and licensing information will be announced here.
