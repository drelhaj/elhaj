AbjadNLP 2027 · Proposed shared task

Kurdish ASTE 2027

Aspect Sentiment Triplet Extraction in Sorani Kurdish

Extracting aspect terms, opinion expressions and sentiment polarity from Sorani Kurdish restaurant reviews written in the Perso-Arabic script.

About the shared task

Fine-grained sentiment extraction

Rather than assigning one sentiment label to an entire review, systems identify the aspect being discussed, the expression conveying an opinion about it and whether that opinion is positive or negative. A sentence may contain zero, one or several triplets.

Input

Sorani Kurdish review sentence

A restaurant-review sentence written in Sorani Kurdish using the Perso-Arabic script.

Output

Aspect–opinion–polarity triplets

A list of triplets containing an aspect string, opinion string and a polarity label of positive or negative. Aspect and opinion strings are copied from the input.

Proposed track 1

Supervised generation

Participants may update model parameters, including fine-tuning encoder–decoder models or large language models on the training data.

Proposed track 2

Few-shot and prompt-based

Participants may use prompts, in-context examples and retrieval over training data, without updating model parameters. Track results are reported separately.

01

Dataset and evaluation

The proposal uses the publicly available KurdABSA dataset, containing Sorani Kurdish restaurant reviews annotated for aspect-based sentiment analysis. JSON and CSV formats are proposed. Exact training, development and test sizes remain to be confirmed.

The proposed main metric is exact-match triplet F1: the aspect string, opinion string and polarity must all match the gold annotation. The submitted proposal specifies a generative formulation; any extension to other modelling approaches or a revised evaluation protocol is still to be confirmed.
